# Sum-Usage-Claude

ภาษาไทย · **[English](README.md)**

แดชบอร์ดที่บอกว่าคุณใช้ Claude Code ไปเท่าไหร่จริง ๆ — อ่านจากไฟล์บันทึกที่ Claude Code เขียนไว้อยู่แล้ว
ไม่ต้องติดตั้งอะไร และไม่เก็บข้อมูลใหม่เพิ่ม

```bash
python3 build_usage.py     # แล้วเปิด index.html
```

ดับเบิลคลิก `index.html` ได้เลย ข้อมูลถูกฝังไว้ในหน้าเว็บแล้ว จึงทำงานแบบออฟไลน์และไม่ต้องมีเว็บเซิร์ฟเวอร์ —
หน้า `file://` ดึงไฟล์ JSON ข้าง ๆ ไม่ได้ ตัว build จึงเรนเดอร์ `template.html` ออกมาเป็น `index.html`
ที่มีข้อมูลอยู่ในตัว แทนที่จะโหลดตอนเปิด

สามแท็บคือ `#overview` `#daily` และ `#day` — เป็นลิงก์ตรงได้ และรีเฟรชแล้วไม่หลุด

## ตอบคำถามอะไรได้บ้าง

- **คุ้มไหม** — ถ้าใช้เท่านี้แต่จ่ายราคา API จะเป็นเงินเท่าไหร่ หารด้วยค่าแพลนรายเดือน อัตราส่วนนั้นคือตัวเลขพาดหัว
- **โทเคนต่อบาท** — โทเคนทั้งหมดต่อเงินที่จ่ายจริง
- **วันไหนหนัก** — มูลค่าต่อวัน และต่อชั่วโมงเมื่อเจาะเข้าไปดูวันนั้น
- **ใช้โมเดลอะไร** — สัดส่วนของแต่ละโมเดล พร้อมบอกว่างานนั้นอยู่โปรเจกต์ไหน

## สามอย่างที่ทำให้ตัวเลขถูก

1. **ตัดซ้ำด้วย `requestId`** — ในการรันจริงครั้งแรก 48% ของเรคอร์ดเป็นของ requestId ที่นับไปแล้ว
   ถ้าไม่ตัด ตัวเลขทุกตัวจะเบิ้ลขึ้นมาเกือบเท่าตัว
2. **คิดราคาโทเคนแคชแยก** — การอ่านแคชคิดที่ 0.1 เท่าของ input และเป็น ~99% ของ input ทั้งหมด
   ถ้าคิดเป็น input ปกติ ยอดจะพองขึ้นราวสิบเท่า
3. **ใช้วันตามเวลาท้องถิ่น ไม่ใช่ UTC** — ไฟล์บันทึกประทับเวลาเป็น UTC ที่ UTC+7 งานตอนกลางคืน
   จะตกไปอยู่วัน UTC ถัดไป ซึ่งจะทำให้การนั่งทำงานดึกทุกครั้งถูกหั่นเป็นสองวัน

## ตัวเลขค่าใช้จ่ายคือ "มูลค่า" ไม่ใช่ "บิล"

บนแพลนรายเดือนคุณจ่ายค่าแพลน จบ ตัวเลขดอลลาร์ทุกตัวในแดชบอร์ดคือ *ถ้าใช้เท่านี้บน API จะเป็นเงินเท่าไหร่*
— เป็นการวัดมูลค่าที่ได้รับ ไม่ใช่เงินที่ต้องจ่าย ค่าแพลนกับอัตราแลกเปลี่ยนตั้งเองได้ในแท็บรอบบิล
(Claude Code ไม่ได้เก็บว่าคุณอยู่แพลนไหน) และค่าที่ตั้งจะถูกจำไว้ในเบราว์เซอร์ เปลี่ยนแล้วเห็นผลทันที
ไม่ต้อง build ใหม่

## ไทยหรืออังกฤษ

มีทั้งสองภาษาในตัว ครั้งแรกจะเลือกตามภาษาเบราว์เซอร์ หลังจากนั้นจำสิ่งที่คุณกดไว้ — เก็บในเบราว์เซอร์
ไม่ใช่ในไฟล์ ภาษาที่เลือกจึงอยู่รอดข้ามการ build ปุ่มอยู่มุมขวาบน ข้างปุ่มสว่าง/มืด

ตารางคำแปลทั้งสองภาษาอยู่ใน `template.html` ใต้ `const I18N` — คีย์ไหนไม่มีคำแปลอังกฤษจะตกกลับไปใช้
ข้อความไทย ไม่ใช่โชว์ชื่อคีย์ เพราะคำแปลที่ยังไม่เสร็จควรดูเหมือนยังไม่เสร็จ ไม่ใช่ดูเหมือนพัง

| ไฟล์ | หน้าที่ |
|---|---|
| `build_usage.py` | อ่านไฟล์บันทึก คิดราคา แล้วเรนเดอร์ `index.html` · ทำงานแบบต่อยอดโดยปริยาย (`--rebuild` เพื่อเริ่มใหม่) |
| `prices.json` | ราคา API แบบ **ระบุวันที่** — ราคาโปรโมชันของ Sonnet 5 หมดวันที่ 2026-08-31 ถ้าเก็บเป็นเลขเดียวจะย้อนไปเปลี่ยนราคาของอดีตโดยไม่มีใครรู้ |
| `template.html` | ตัวแดชบอร์ด · `build_usage.py` แทนข้อมูลลงไปในไฟล์นี้ |
| `billing_cycles.example.json` | ตัวอย่างรูปแบบรอบบิล คัดลอกเป็น `billing_cycles.json` แล้วใส่ของจริง — ไฟล์จริงถูก gitignore ไว้ |
| `data/`, `index.html` | ไฟล์ที่ถูกสร้างขึ้น — gitignore ไว้ |

เขียนออกมาเฉพาะจำนวนกับค่าใช้จ่ายเท่านั้น ไม่มีข้อความที่คุณพิมพ์ ไม่มีคำตอบ และไม่มี path
นอกจากชื่อโฟลเดอร์โปรเจกต์
